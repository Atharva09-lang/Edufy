# 🎓 Edufy

> **AI-Powered MERN Learning Platform** built for modern online education with secure authentication, course management, Razorpay payments, Cloudinary media storage, and a **Groq API-powered AI Doubt Assistant**.

---

## 🚀 Highlights

- 🔐 JWT Authentication & Email OTP Verification
- 👨‍🎓 Student & Instructor Dashboards
- 📚 Course Creation & Enrollment
- 🤖 AI Doubt Assistant using Groq API
- 💳 Razorpay Payment Integration
- ☁️ Cloudinary Media Uploads
- ✨ Modern Glassmorphism UI with Smooth Animations

---

## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|
| **Frontend** | React, Tailwind CSS, Redux Toolkit |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB, Mongoose |
| **Authentication** | JWT, OTP |
| **AI** | Groq API |
| **Payments** | Razorpay |
| **Media Storage** | Cloudinary |
